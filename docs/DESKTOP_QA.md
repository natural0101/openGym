# Desktop verification

Verified on Windows 11 x64, Node 24.17.0, Electron 44.4.5.

## Automated evidence

- Frontend: **127 test files, 1,585 tests passed** (`npm --prefix frontend test -- --maxWorkers=4`). Includes existing workout/progression/import regression coverage and the new home-plan catalogue invariants.
- Storage: **6 tests passed** (`npm run test:desktop`): ordered durable writes, validation before replacement, damaged-file recovery preserving the original, explicit restore after unrecoverable corruption, retention of 30 import snapshots, missing-primary recovery and rejection of damaged recovery files.
- Electron workflow: `npm run test:smoke` runs in an isolated test profile. New empty state → template preview → four routines → start → mark a set → close/reopen → resume → finish → saved history. Native JSON export, invalid import rejection, valid import with confirmation, PDF generation, Russian exercise search, no-results state, Ctrl+K navigation, settings and theme controls are exercised.
- The core workflow produces **zero renderer exceptions and zero HTTP/backend requests**. It starts while the browser context is offline. Local exercise media, when provided by the optional fixture, is read through the app protocol.
- Windows NSIS x64 installer generated by `npm run dist`; no publisher certificate is configured.
- Optional media downloader completed **2,648 / 2,648 files, zero errors**, using the pinned upstream revision. Images/animations are not included in Git or the installer.

Local command logs, machine-readable smoke results and screenshots are produced under `desktop/test-output/` (gitignored because the test profile contains synthetic workout records and local filesystem paths).

Installed verification: NSIS installer exited 0. The actual installed executable reported `packaged: true`; the four home routines and dark theme survived a full restart. All 2,648 media files were available, and the routine editor loaded local images with networking disabled. No workout history was inserted in the real profile.

## Product and visual review

The initial card dashboard was rejected by the user and replaced. The current interface uses a neutral dark workspace, persistent sidebar, program table with start/edit actions, and tabs for schedule and recent sessions. It contains no fabricated activity. Settings use plain separated sections. Active workouts place demonstrations beside set controls and expose an exercise outline on wide windows. No self-assigned design score or user acceptance is claimed.

Native Electron screenshots cover a 1380×920 window, an 820×720 compact window, light and dark themes, empty profile, plan preview, weekly schedule, active workout, plan, library, settings and search. The narrow-window sidebar hides its labels; explicit assertions check that they stay hidden. The tab workflow, exercise outline and explicit desktop exercise-removal control are exercised by the smoke test. The upstream routine drag/move suites were rerun after changing the shared row component: 30 tests passed. Routine list rows show stored schedule/history and open the existing editor.

Segoe UI system typography, neutral surfaces, fine separators and compact controls are shared across the desktop routes. No remote fonts or motion libraries. Toast placement is separated from the bottom-right rest timer, and exercise image controls do not overlap. Reduced-motion preferences disable transitions.

Template application preserves existing routines and assigned weekdays. Import previews counts and keeps a snapshot before replacement. The native save status distinguishes loading/saving/saved/error. Media readiness comes from actual files, with pause/resume and error retry. Ctrl+K, Enter, Escape and trapped Tab navigation are implemented.

## Remaining limits

- Unsigned installer: Windows may show a publisher/SmartScreen prompt.
- Reboot of the Windows host, other Windows versions and a second physical computer were not tested.
- No automatic updater, desktop AI coach or synchronization is included. The app is intentionally one local profile.
- Full accessibility audit/high-contrast Windows mode was not performed. Russian names were added for the home-plan exercises; the rest of the upstream catalogue generally retains English exercise names, with Russian instructions where provided upstream.
- Media licensing is separate from the app; see NOTICE.md. Backups on the same disk do not protect against loss of the disk.
